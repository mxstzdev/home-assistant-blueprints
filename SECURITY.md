# Security Policy

## Supported versions

Only the latest release of each blueprint receives fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately via
[GitHub's private vulnerability reporting](https://github.com/mxstzdev/home-assistant-blueprints/security/advisories/new)
(**Security → Report a vulnerability**).

Examples in scope: blueprint logic that can unlock, disarm, open or otherwise act on a
device unexpectedly, or that exposes sensitive data. Vulnerabilities in Home Assistant
itself belong to the [Home Assistant project](https://www.home-assistant.io/security/).

This is a personal project, so responses are best effort.
